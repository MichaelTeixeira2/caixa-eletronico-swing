# 🏧 Caixa Eletrônico (Java Swing)

Caixa eletrônico de treinamento com interface gráfica em Java Swing.

## Funcionalidades

- Informar titular e saldo
- Depositar e sacar, com escolha da operação numa caixa de seleção
- Teclado numérico na tela
- Extrato de todas as operações
- Validação de campos vazios, valores inválidos e saldo insuficiente

## Conceitos praticados

- `BorderLayout`, `FlowLayout` e `GridLayout`
- `JPanel`, `JLabel`, `JTextField`, `JButton` e `JComboBox`
- `JList` com `DefaultListModel` e `JScrollPane`
- `ActionListener` e `JOptionPane`
- `try/catch` com `NumberFormatException`


## O que aprendi

Aprendi usar funções de JFrame para gerenciar contas banárias, além de aplicar conceitos vistos 
em sala de aula.
